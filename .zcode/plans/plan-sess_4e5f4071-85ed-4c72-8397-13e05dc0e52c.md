## 目标

把"日志采集 + 日志存储"整域从 `internal/monitor`（56 文件、193 个 Handler 方法、五域混装）抽成新包 `internal/logcollect`，让 monitor 只剩 exporter 目标、告警/通知、Prometheus、软件包仓库、主机列表。

**核心原则：本次只搬家、不改逻辑**（pure move），外部行为零变化、测试全绿；结构再优化留给计划里的 Phase 0/2。这样这次改动可以靠"测试全绿 + 路由清单比对"验证，而不是靠读代码。

## 已确认的关键事实

- **全仓只有 `router.go` 一个文件 import monitor**（`router.go:19`），所有外部耦合点集中在 `router.go:359-457`。改动影响面可控。
- `internal/assets` 不依赖 monitor，它走 `internal/shared/logstream`（`log_setting.go:9,48`）。
- **ES 客户端只有日志域在用**：`elasticsearchRequest` 的使用者全是 log/ES 文件，alert/target/package 一律不用 → ES 三件套（客户端、集群 CRUD、pipeline）整体进 logcollect，monitor 从此零 ES 依赖。
- `log_health.go:316` 与 `handler.go:27` 的 Handler 混装了多域职责。
- **代码库既有约定是"各包自备小工具"**：`parseID` 在 inspection 与 monitor 各一份；批量删除 body 解析在 assets(`batchDeleteIDs`)、automation(`batchIDs`)、monitor(`batchTargetIDs`/`logTargetIDs`) 各有各的。→ 不新建公共 util 包。

## 唯一新增的共享包

`internal/shared/filebeat`（1 文件），因为内置 Playbook/unit 内容是**两个域都需要的领域知识**：monitor 的软件包创建/编辑/回填要用（`package_mutation.go:76,82,89,134,152`），logcollect 下发时要兜底 service unit（`log_target_actions.go:221`）。按现有 `internal/shared/` 约定（单文件、小写单数包名、中文包注释）：导出 `InstallPlaybookContent()` / `UninstallPlaybookContent()` / `ServiceUnitContent()`。

## 依赖注入

现在 `secrets` 与 `packageRoot` 由 `monitor.NewHandler` 内部创建（`handler.go:46-56`），logcollect 两个都要用 → 提升到 router 构造一次、显式注入两包，`monitor.NewHandler` 签名随之调整（调用点只有 router，可控）。

```go
type Handler struct {          // logcollect：不带 prometheus client，也不带 smtpSend
    db, gateway, jobs, secrets, packageRoot, refreshHostInfo
}
func NewHandler(db, gateway, jobs, secrets, packageRoot) *Handler
func (handler *Handler) SetHostInfoRefresher(...)
```

logcollect 自带自己的 `parseID` / `ids(context)` / `firstNonEmpty` / `stringValue` / `deleteRowsAffected` / `batchDeleteRows` 副本，跟既有约定一致；monitor 侧保留自己的（`deleteRowsAffected`、`batchDeleteMonitorRows` 被 `alert_config.go` 用）。

## 路由

`router.go:394-457` 的 **46 条**路由 `monitorHandler.` → `logcollectHandler.`（`/log-targets/*`、`/log-datastreams/*`、`/log-retention-tiers/*`、`/log-processing-rules/*`、`/log-collection-filter-rules/*`、`/elasticsearch-clusters/*`）。`monitorRoutes` 组与权限不变，只换 handler 实例——**URL 全部不变，前端零改动**。
