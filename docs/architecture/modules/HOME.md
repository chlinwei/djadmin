# 首页

> **运维工作台展示当前账号可查看的概览和最近记录，不替代各业务模块。**

## 菜单入口

顶级「首页」，路由 `/index`。登录后默认进入工作台；首次进入和切回首页时加载，不在后台轮询。时间按当前用户时区显示。

## 导航流程

```mermaid
flowchart LR
    A["登录后进入首页或切回"] --> B["GET /sys/home/overview/"]
    B --> C["校验登录并按业务查看权限查询"]
    C --> D["展示概览、近期动态与快捷入口"]
    D --> E["打开对应业务标签页"]
    C --> F["单模块失败：该模块标记不可用"]
```

## 指标口径与权限

| 区块 | 统计口径 | 最近记录 | 查看权限 |
|---|---|---|---|
| 主机资产 | 平台登记的主机总数 | — | `assets:hosts:view` |
| 触发中告警 | 平台已接收、状态仍为 `firing` 的告警历史记录；不是 Prometheus 实时查询 | 按触发时间倒序最多 5 条 | `monitor:view` |
| 运行中作业 | 当前状态为 `running` 的作业数，不含等待队列 | 按记录 ID 倒序最多 5 条，不限状态 | `automation:jobs:view` |
| 失败巡检 | 近 24 小时内发起且当前为 `failed` 的巡检执行数 | 按记录 ID 倒序最多 5 条，不限状态 | `inspection:view` |

概览接口复用 MySQL / PostgreSQL 的业务查询，不需要迁移。未授权的区块不查询也不返回；读取失败的已授权区块返回 `unavailable`，页面显示“暂时无法获取”，不把失败显示为零。真实零值和空列表照常展示。

## 快捷入口

- 业务链接按概览接口返回的已授权区块展示，实际业务请求仍由目标接口独立鉴权。日志中心与告警共享 `monitor:view` 查看权限。
- 文档中心是公共入口，但阅读操作说明不会授予对应业务权限。
