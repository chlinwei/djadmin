# 个人中心

> **个人时区控制界面时间显示，不改变后端 UTC 存储，也不改变定时任务的 cron 调度时区。**

## 入口与功能

右上角用户菜单 → 个人中心。

| 页面区域 | 功能与重点 |
|---|---|
| 基本资料 | 修改手机号码、时区；角色信息仅用于查看 |
| 修改密码 | 提交旧密码与新密码，旧密码校验不通过则拒绝 |
| 告警媒介 | 选择已有媒介，维护自己的收件地址及启用状态 |
| 头像 | 上传支持的图片，受文件大小和扩展名约束 |

## 修改密码流程

```mermaid
flowchart TD
    A["输入旧密码、新密码与确认值"] --> B["前端校验并提交"]
    B --> C["后端按当前身份读取用户"]
    C --> D{"旧密码校验通过？"}
    D -->|否| E["拒绝并显示错误"]
    D -->|是| F["生成随机盐与 PBKDF2 摘要"]
    F --> G["写入新密码摘要"]
    G --> H{"写入成功？"}
    H -->|否| E
    H -->|是| I["返回修改成功"]
```

修改成功不等于服务端撤销所有已签发 JWT，完整会话边界见 [登录认证与权限](ACCESS.md)。

## 接收告警需要哪些条件

```mermaid
flowchart LR
    A["管理员配置可用媒介"] --> B["用户绑定收件地址并启用"]
    B --> C["告警命中通知策略出口"]
    C --> D["满足事件开关和用户组范围"]
    D --> E["产生投递并查看发送结果"]
```

**只绑定邮箱不保证收到所有告警。** 收不到时从通知链路诊断查看策略、媒介、组限制与投递状态。
安全退出会清理本浏览器存储并回到登录页，不等于全端令牌撤销。
