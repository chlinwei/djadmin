# 告警媒介配置完整指南

## 📌 概念说明

告警媒介系统分为三个层次：

### 1️⃣ **媒介层（管理员操作）**
- **位置**: `监控管理 > 告警媒介`
- **职能**: 创建和配置告警媒介类型
- **包含内容**:
  - 媒介名称 (例如: "公司邮箱", "部门邮箱")
  - 媒介类型 (当前支持: Email)
  - SMTP 配置 (服务器、端口、认证方式、发件人邮箱、密码等)
  - 消息格式 (HTML/文本)
- **权限**: 仅系统管理员可操作

### 2️⃣ **通知策略层（管理员操作，对齐 Grafana notification policy）**
- **位置**: `监控管理 > 通知策略`
- **职能**: 维护策略树，决定"哪些告警 → 发到哪些媒介"
- **规则**:
  - 根节点「默认策略」恒命中、系统内置；从根向下逐层取第一条命中的子策略，最深命中节点决定出口
  - 匹配条件：标签匹配（`=` / `!=` / `=~` / `!~`）与服务树节点匹配（业务/环境/服务/项目）
  - 出口媒介：留空继承父节点；显式置空 = 静音；由最深命中节点决定 firing / resolved 通知开关
- **权限**: 仅系统管理员可操作

### 3️⃣ **绑定层（个人用户操作）**
- **位置**: `用户中心 > 个人设置 > 告警媒介`
- **职能**: 配置个人的媒介绑定和收件人（只决定"发到我的哪些邮箱"，订阅范围由通知策略统一决定）
- **包含内容**:
  - 选择要使用的媒介（来自管理员创建的媒介列表）
  - 为每个媒介配置自己的收件人邮箱
  - 启用/禁用各个媒介绑定
- **权限**: 每个用户可配置自己的绑定

## 🔧 操作流程

### Step 1️⃣: 管理员创建媒介（仅做一次）

进入 **监控管理 > 告警媒介**，点击 **添加媒介** 按钮：

```
表单字段填写:
├─ 媒介名称: "公司邮箱系统"
├─ 媒介类型: Email
├─ 选择方案:
│  ├─ Gmail 方案 (自动填充 smtp.gmail.com:587)
│  └─ 自定义方案 (手动配置 SMTP)
├─ 发件人邮箱: alerts@company.com
├─ 用户名 (可选): smtp-user@company.com
├─ 密码: app-password-or-token
├─ 消息格式: HTML
└─ 说明: "用于系统告警通知"
```

✅ **保存** → 媒介创建完成

### Step 2️⃣: 普通用户配置个人绑定

进入 **用户中心 > 个人设置 > 告警媒介** 选项卡：

#### 方式 A: 添加新绑定

1. 点击 **添加媒介绑定** 按钮
2. 在弹窗中:
   - **告警媒介**: 从下拉列表选择 (例如: "公司邮箱系统 (email)")
   - **收件人邮箱**: 输入你的邮箱地址，支持多个:
     ```
     my-email@personal.com
     backup@personal.com
     ```
   - **启用此绑定**: 开启开关
3. 点击 **添加** 按钮

#### 方式 B: 编辑已有绑定

1. 在绑定表格中找到要修改的媒介
2. 点击 **编辑** 按钮 (铅笔图标)
3. 修改收件人邮箱或启用状态
4. 点击 **更新** 按钮

#### 方式 C: 删除绑定

1. 在绑定表格中找到要删除的媒介
2. 点击 **删除** 按钮 (X 图标)
3. 确认删除

## 📊 告警流程示例

当监控告警触发时：

```
告警规则匹配
    ↓
通知策略树路由（逐层取第一条命中的子策略，最深命中节点决定出口）
    ↓
查询出口媒介 (例如: "公司邮箱系统")
    ↓
查询所有用户对该媒介的绑定
    ↓
聚合所有用户的收件人邮箱
    ↓
发送邮件到所有收件人
    ↓
记录通知事件状态
```

**例子**: 
- 告警触发（severity=critical）
- 策略「严重告警」（默认策略的子策略，条件 severity=critical）出口为媒介 "公司邮箱系统"
- 用户 A 绑定了该媒介，收件人为: user-a@company.com
- 用户 B 也绑定了该媒介，收件人为: user-b@company.com, user-b-alt@company.com
- 邮件发送到: user-a@company.com, user-b@company.com, user-b-alt@company.com

## 🎯 使用场景

### 场景 1: 多个收件人

用户可以为同一个媒介配置多个邮箱地址（例如：工作邮箱 + 个人邮箱备用）

```
媒介绑定表:
┌──────────────┬──────────────────────────────────────┬────────┐
│ 媒介名称     │ 收件人                               │ 状态   │
├──────────────┼──────────────────────────────────────┼────────┤
│ 公司邮箱系统 │ alice@company.com                   │ 已启用 │
│              │ alice.backup@personal.com           │        │
└──────────────┴──────────────────────────────────────┴────────┘
```

### 场景 2: 多个媒介

用户可以使用多个不同的媒介，为不同优先级告警配置不同的通知方式

```
媒介绑定表:
┌──────────────┬──────────────────────────────────┬────────┐
│ 媒介名称     │ 收件人                           │ 状态   │
├──────────────┼──────────────────────────────────┼────────┤
│ 公司邮箱系统 │ alice@company.com               │ 已启用 │
│ 备用邮箱     │ alice.personal@gmail.com        │ 已启用 │
│ 紧急通知     │ alice.phone-email@carrier.com   │ 已启用 │
└──────────────┴──────────────────────────────────┴────────┘
```

通知策略可以配置（同一媒介树不同分支）：
- 严重告警（severity=critical 子策略）→ 出口"紧急通知"媒介
- 一般告警 → 出口"公司邮箱系统"媒介
- 信息告警 → 出口"备用邮箱"媒介

### 场景 3: 禁用某个媒介

用户可以禁用某个绑定（例如：休假期间不想收到某些告警）

```
点击编辑 → 关闭"启用此绑定"开关 → 更新
```

## ⚠️ 常见问题

### Q1: 为什么我在用户中心看不到任何媒介？
**A**: 管理员还没有创建任何媒介。请让管理员先在"监控管理 > 告警媒介"中创建媒介。

### Q2: 我能创建自己的媒介吗？
**A**: 不能。媒介只能由系统管理员创建。你可以配置使用管理员创建的媒介。

### Q3: 我配置了收件人，但没有收到告警邮件？
**A**: 可能的原因：
1. ❌ 你的绑定被禁用了 → 启用它
2. ❌ 收件人邮箱地址有错 → 检查格式（必须包含 @）
3. ❌ 没有告警规则触发 → 检查告警规则配置
4. ❌ 告警未被任何策略出口命中（或出口为静音）→ 检查 `监控管理 > 通知策略` 的策略树配置
5. ❌ 邮件被发件人 SMTP 服务拒绝 → 检查媒介配置和邮箱认证

### Q4: 邮件格式可以改成 HTML 吗？
**A**: 可以。但这是由管理员在创建媒介时配置的，个人用户无法修改。请联系管理员。

### Q5: 能为不同的告警配置不同的收件人吗？
**A**: 是的！创建多个媒介，每个媒介配置不同的收件人。然后在 `监控管理 > 通知策略` 中为不同条件的子策略配置不同的出口媒介。
