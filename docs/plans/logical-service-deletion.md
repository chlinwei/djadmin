# 逻辑服务删除范围

状态：删除链路已实现，尚未部署迁移或执行线上删除。最终逻辑、部署前置条件与历史归属边界见
[日志采集架构](../architecture/LOG_COLLECTION_ARCHITECTURE.md#逻辑服务删除与日志撤销)。

## 范围

仅改造“删除逻辑服务”操作，不扩展其他资源的删除功能。

| 逻辑服务所属数据 | 目标行为 |
| --- | --- |
| 逻辑服务记录 | 删除 |
| 该服务的成员关联、专属成员部署实例记录 | 删除；不得误删其他服务仍在使用的共享实例 |
| 该服务的配置、宏值、日志认证状态 | 删除 |
| 该服务的日志采集任务 | 撤销并停止采集，防止清理后继续写入 |
| 该服务在 Elasticsearch 中的历史日志 | 立即删除，不等待保留策略到期；不得误删其他服务的日志 |

## 边界

- 不删除主机资产或真实主机。
- 不删除、卸载或启停实际应用及 QManager，不执行 start/stop。
- 不删除主机上的原始日志文件。
- 不删除公共应用、版本、模板、解析规则及其他服务的数据。
- 清理失败必须明确反馈，不得仅删除服务记录就报告全部成功。
- 本需求记录不授权执行任何线上删除。
